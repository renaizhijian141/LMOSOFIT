# Physics-guided model of lunar magma ocean solidification time


A physics-guided regression model relating the lunar magma ocean (LMO)
solidification time to crustal thermal conductivity (`k_cr`), crustal
thickness (`h_cr`) and initial heat production (`H`). The repository
contains the least-squares fitting code, sensitivity analysis, and 3D
response-surface visualization used in the accompanying paper.

## Contents

| File | Description |
| :--- | :--- |
| `Fitting.py` | Fits the physics-guided model, reports fit statistics and coefficient uncertainties, and performs sensitivity analysis (MEM, AME, stratified effects). |
| `Plot.py` | Generates the 3D response surfaces for H = 10, 15, 20, 25 pW/kg with observed data points overlaid. |
| `04-Table S5.xlsx` | Dataset: 264 1-D thermal simulations (sheet `Table S5`, header on row 2). |
| `Physical_model_3D_surfaces_with_legend.png` | Example output figure generated by `Plot.py`. |

## Data

`04-Table S6.xlsx`, sheet `Table S5`, four columns:

- `Thermal conductivity (W/m/K)` — `k_cr`, 1.5–2.0
- `Crustal thickness (km)` — `h_cr`, 39–49
- `Initial heat production (pW/kg)` — `H`, 10, 15, 20, 25
- `LMO solidification time (Myr)` — `t`
